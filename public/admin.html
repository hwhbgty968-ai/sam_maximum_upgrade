Sam's database is Postgres, which keeps its own restore history (on Neon's free plan: the last 6 hours). For copies you keep, download a full backup here, or run npm run backup on your computer with DATABASE_URL set. To restore one: npm run restore -- file.json into an empty database.

Sam also copies its SQLite file automatically once a day and keeps the newest 14, on the server at . Download a full backup too, so a copy lives somewhere else.
